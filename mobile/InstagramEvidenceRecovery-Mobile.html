Reprendre un dossier

Comment ça marche

  1. Tu saisis le nom d'utilisateur de ton compte.
  2. Tu choisis ton archive Instagram (le fichier ZIP) depuis ton téléphone.
  3. L'analyse se fait sur l'appareil : conversations, abonnés, chronologie, éléments manquants, empreintes.
  4. Tu peux enregistrer un rapport (HTML, JSON, CSV) dans tes fichiers.

Aucune connexion Internet n'est nécessaire après l'ouverture de cette page. Tu peux la mettre en mode avion : tout continue de fonctionner.

Ce que cette version ne fait pas

  • Aucun piratage, aucun contournement d'Instagram, aucun identifiant.
  • Aucune reconstitution de contenu absent : une absence reste une absence.
  • Pas de collecte de la page publique (le navigateur l'interdit depuis un fichier local) : utilise la version ordinateur pour cela.
  • Pas d'accès aux messages privés autrement que par ton propre export officiel.
